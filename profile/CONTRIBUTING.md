# Contributing to ReadyToDev.Pro

First of all - **thank you for being here.** Every contribution, no matter how small, helps thousands of developers learn better and get hired faster.

This guide explains how you can help improve ReadyToDev.Pro resources.

---

## Who Can Contribute?

**Everyone.** You don't need to be a senior developer. In fact, some of the best contributions come from people who just learned something - because you remember exactly what was confusing.

- Just learned JavaScript? Help us improve the JS roadmap.
- Went through a frontend interview recently? Share questions you were asked.
- Found a typo? Fix it. Seriously, that counts.

---

## Ways to Contribute

### 1. Report an Issue
Found something wrong, outdated, or confusing?

- Open a **GitHub Issue** in the relevant repository
- Describe what's wrong and where
- If you know the fix - even better, see below

### 2. Fix a Typo or Error
Small fixes are incredibly valuable.

- Fork the repository
- Make your change
- Open a Pull Request with a short description

### 3. Add an Interview Question
Know a question that's missing from our list?

- The question should be real - something you've seen in an actual interview or a well-known resource
- Include a clear, beginner-friendly answer
- Add it to the correct category (HTML / CSS / JavaScript / React / General)

### 4. Improve a Roadmap
Think a topic is missing, in the wrong order, or needs a better explanation?

- Open an Issue first to discuss the change
- We'll review and merge if it fits the roadmap's vision

### 5. Suggest a Resource
Know a great free resource (article, video, docs page) that helped you?

- Add it to the relevant section in `web-development-resources`
- Include: resource name, URL, and one sentence why it's useful
- **Free resources only** - no paid courses or affiliate links

### 6. Translate Content
Want to make this accessible in another language? We'd love that.

- Open an Issue to discuss which content you'd like to translate
- We'll set up the right folder structure together

---

## Before You Submit a Pull Request

Please make sure:

- [ ] Your change is in the right file and category
- [ ] The language is clear and beginner-friendly
- [ ] No broken links
- [ ] No promotional or affiliate content
- [ ] One topic per Pull Request (easier to review)

---

## The Process

1. **Fork** the repository
2. **Create a branch** - name it something clear, e.g. `add-react-interview-question`
3. **Make your changes**
4. **Open a Pull Request** with a short description of what and why
5. We'll review it within a few days and either merge or leave feedback

---

## Code of Conduct

Be kind. Be helpful. Be constructive.

We're all here to learn and grow. Disrespectful or discouraging behavior won't be tolerated - this is a safe space for developers at every level.

---

## One Last Thing

If ReadyToDev.Pro has helped you in any way - **star the repository.** It takes 2 seconds and helps other developers discover these resources.

Thank you for making the dev community better.
